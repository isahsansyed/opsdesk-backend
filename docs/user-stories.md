# User Stories

## Customer Stories
- **As a Customer**, I want to submit a support ticket describing my payment or technical issue so that support agents can investigate it.
- **As a Customer**, I want to view the real-time status of my open tickets so that I know when a fix is underway.
- **As a Customer**, I want to add comments and upload screenshots to an open ticket to provide extra context.

## Support Agent Stories
- **As an Agent**, I want to view unassigned tickets belonging to my team so that I can self-assign relevant issues.
- **As an Agent**, I want to post internal notes on a ticket that are hidden from the customer so my team can collaborate safely.
- **As an Agent**, I want to change a ticket's status to `RESOLVED` when the issue is fixed so that the customer is notified.

## Manager & Admin Stories
- **As a Manager**, I want to reassign tickets between agents to balance workload distribution.
- **As an Admin**, I want to review ticket audit histories to ensure compliance and track who modified specific fields.
